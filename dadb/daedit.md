# Wie füge ich etwas hinzu?

## Neue Kalenderwoche erstellen

1. Öffne den Ordner `datagebuch`.
2. Erstelle eine Markdown-Datei für die neue Kalenderwoche. Verwende das Namensschema der vorhandenen Dateien.
3. Übernimm die Struktur der letzten Kalenderwoche und ergänze Agenda und Ergebnisse.
4. Öffne `datagebuch/datb.md` und füge einen Link zur neuen Datei im passenden Jahr ein.
5. Speichere die Änderungen mit einer aussagekräftigen Commit-Nachricht.

## Bestehenden Eintrag bearbeiten

1. Öffne die gewünschte KW-Datei.
2. Wähle das Stiftsymbol (**Edit this file**).
3. Bearbeite den Inhalt.
4. Speichere die Änderung mit **Commit changes**.

## PDF-Dateien und Bilder hochladen

1. Öffne den passenden Ordner im Repository.
2. Wähle **Add file → Upload files**.
3. Lade die Datei hoch.
4. Achte darauf, dass Dateiname und Markdown-Link exakt übereinstimmen.

## Änderungen kontrollieren

Öffne nach dem Commit die Startseite und teste die neu hinzugefügten Links.
