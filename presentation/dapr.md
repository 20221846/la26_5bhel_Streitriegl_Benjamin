# Präsentationen

Auf dieser Seite werden die Präsentationen zur Diplomarbeit gesammelt.

## Präsentationsunterlagen

- Zwischenpräsentation – Datei wird ergänzt, sobald sie vorliegt.
- Abschlusspräsentation – Datei wird ergänzt, sobald sie vorliegt.

Neue Präsentationsdateien können in diesem Ordner abgelegt und anschließend hier verlinkt werden.
